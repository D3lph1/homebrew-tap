# homebrew-tap

Homebrew formulae for [d3lph1](https://github.com/d3lph1)'s projects.

```bash
brew install d3lph1/tap/mcp-atlassian
```

## Formulae

| Formula | Description |
|---|---|
| [`mcp-atlassian`](https://github.com/d3lph1/mcp-atlassian) | Lightweight MCP server for Jira and Confluence |

The formulae install prebuilt binaries from each project's GitHub releases —
nothing is compiled locally.
